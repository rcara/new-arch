Paramètres

Administration avancée

Opérations de maintenance du foyer, réservées au compte principal. Elles s'exécutent sur la machine qui héberge New Arch, application arrêtée.

Sauvegarde

Une archive complète : base, coffre et médiathèque. À faire régulièrement et à conserver hors de la machine.

Détails techniques

python cli.py backup — archive créée dans le dossier backups/.

Restauration

Recrée un foyer à partir d'une archive, dans un dossier neuf. Le foyer actuel n'est jamais écrasé.

Détails techniques

python cli.py restore <archive> <dossier-neuf>

Chiffrement des fichiers

État : {% if crypto.enabled %}Activé{% else %}Non activé{% endif %}

Chiffre les fichiers du coffre et de la médiathèque avec une phrase secrète. La base de données reste lisible sur la machine.

Détails techniques

python cli.py crypto enable, puis variable FOYER_PASSPHRASE au démarrage. Voir docs/v2/10_ENCRYPTION.md.

Foyer de démonstration

Des données fictives pour découvrir New Arch, uniquement dans un dossier vide — jamais dans ce foyer.

Détails techniques

python cli.py seed-demo avec un FOYER_HOME neuf. Voir GUIDE.md et WINDOWS.md.
